# Upstream feature and correctness review

Reviewed on 2026-09-30 against these pinned references:

- Fork baseline: `4738d1701a13c626474fc2cdb9edbcaffc1b22db` (`v0.11.22`).
- Android upstream: [HuangAntimony/Hoshi-Reader-Android](https://github.com/HuangAntimony/Hoshi-Reader-Android), `upstream/main` at `c8137ea94b75acb4d2dbcaba383ed1c5156eb6f1` (after `v1.4.0`).
- Current iOS behavior: [Manhhao/Hoshi-Reader](https://github.com/Manhhao/Hoshi-Reader), `origin/develop` at `16a2f00c997f89c967e13844e76f06f5cf1d37fb`. The checked-out reference remains `839d4864698fae65c384b25f92ee94feaa37eefb`; newer behavior was inspected directly from the fetched ref without changing the submodule.

This is a targeted assessment of correctness fixes and useful features, based on implementation and tests as well as history. It is not a recommendation to merge the upstream branch wholesale: the fork has its own manga and sentence readers, translation features, always-on statistics, optimistic streak reconstruction, and incremental HTTP sync.

## Existing behavior to retain

- **Supplementary-plane lookup safety** ([upstream fix](https://github.com/HuangAntimony/Hoshi-Reader-Android/commit/17f9070f777b7e79f1f43f85bc65a7652aace3ee)): already independently implemented. `ReaderSelectionScripts` and popup selection normalize a caret between surrogate halves, scan complete code points, and preserve UTF-16 DOM ranges. `ReaderSelectionUnicodeWebViewTest` exercises both scripts with real DOM geometry; `SentenceLookupQueryTest` covers the native sentence reader. Importing the newer shared-web-assets architecture is unnecessary for this behavior.
- **Reading-day reset**: the fork already exposes a 3am default and reading-minute goal with optimistic legacy reconstruction. Upstream's reset controls and later split autostart controls are not a replacement for the fork's deliberately always-on tracking. Current iOS `StatisticsSettingsView` also still exposes one autostart mode, so the Android upstream split is not a simple parity fix.
- **Fast HTTP sync**: keep the fork's metadata delta index, ETag/body cache, statistics lane, per-book serialization, and unchanged-library request budgets. Upstream TTU/Drive work does not replace this custom protocol. Transfer correctness fixes independently and keep tests for both unchanged and changed remote state.
- **Packed-EPUB cache recovery** ([upstream fix](https://github.com/HuangAntimony/Hoshi-Reader-Android/commit/53547188a8365f3ff8602b50c7857765dd8e8663)): not directly applicable. That fix rebuilds a disposable extraction cache from a retained packed EPUB. This fork imports into extracted book storage and does not use the same packed-cache lifecycle.
